# 倬的天氣

桌面天氣小工具，並提供語音總控每晚 21:00 播報「明天天氣＋穿著建議＋空品警戒＋颱風影響」。

> 目前是 v0.6.0：功能都做好了，等共用簽章與氣象署授權碼核對後發版。沒有氣象署授權碼時，預報用 Open-Meteo 備援（查不到颱風）。

## 解決什麼問題

- 晚上不用打開 APP，語音總控會在唸明天行程後接著唸明天天氣，並建議穿什麼、要不要帶傘。
- 明天要上班就唸學校的天氣，放假就唸家裡的（依人事總處辦公日曆）。
- 空氣品質到橘色以上、或有颱風時才會多唸；颱風會說預估什麼時候最接近，以及家和學校各自會不會受影響。

## 安裝與首次設定

1. 下載 APK 安裝（新功能先裝 LAB 版）。
2. 打開 APP，允許定位（建議選「一律允許」，小工具才會跟著位置更新）。
3. 設定頁填家、學校所在的鄉鎮，以及氣象署授權碼、環境部金鑰（各有測試按鈕）。
4. 照健康檢查頁的指示，在 ColorOS 打開「自啟動」「關聯啟動」，電池設成「不限制」。
5. 長按桌面空白處 → 小工具 → 倬的天氣，放 4×1 或 2×2。

## 小工具

- 4×1 有兩種版面：A＝現在＋未來 4 天；C＝左邊現在、右邊明天。點右側的圓點切換。
- 想同時看兩種，就放兩個小工具，一個設 A、一個設 C。

## 語音指令範例

「明天天氣怎樣」「明天要帶傘嗎」「現在外面幾度」「要不要戴口罩」「颱風會不會來」「把學校設成現在這裡」

## 備份與還原

設定頁 →「7 備份」：分享備份、存到檔案、匯入（合併或取代）；匯入前會自動備份，可以按「復原到匯入前」。備份只有設定和家、學校地點，不含授權碼。

## 常見問題

- **為什麼小工具不能用滑的切換？** Android 桌面小工具只收得到點擊，所以改成點圓點。
- **資料從哪來？** 中央氣象署、環境部；氣象署連不上時改用 Open-Meteo。

## 提醒

- 颱風陸上警報：家或學校所在縣市進入陸上警報時通知。
- 明天空品紫色以上時通知。
- 早上降雨提醒（預設 06:50）：今天降雨機率 30% 以上才提醒。設定頁有「測試通知」。

## 健康檢查

設定頁 →「健康檢查」：定位、通知、電池、ColorOS 自啟動與關聯啟動、授權碼、最近更新、小工具、Agent API。紅點或黃點旁邊有按鈕可以直接去設定。
