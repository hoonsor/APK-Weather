# DESIGN：倬的天氣

> 倬 2026-11-10 確認「定案草稿：A＋C」。設計稿：`docs/design/mockups.html` 第一個分頁（claude.ai artifact「倬的天氣：版面設計方案」https://claude.ai/artifact/WbQQJfg7Z9cGDz5fAKwEfo）。
> 色票**只有這一份**：程式裡的 `ui/theme/Palette.kt` 與小工具的 `res/values/colors.xml` 都照這張表，改色先改這裡。

## 1. 定案內容

| 項目 | 決定 |
|---|---|
| 桌面小工具 | **4×1**，兩種版面：A＝現在＋未來 4 天（透明，字疊在桌布上）、C＝左「現在」右「明天」（實心藍紫面板）。右側一排兩顆圓點是切換鈕，點一下換版面；每個小工具各自記住 |
| 2×2 小工具 | 兩個：「現在」（溫度、高低溫、降雨、明天穿著圖示）、「明天」（溫度範圍、白天→晚上降雨、穿著圖示） |
| APP 主畫面 | 方案 A 夜空樣式；「明天」用方案 C 的大卡（大圖示、溫度範圍、播報句、穿著標籤、唸給我聽） |
| 主畫面順序 | 地點切換列 → 現在（大字溫度＋4 格數據）→ 颱風卡（有才出現）→ 明天大卡 → 7 日（每天穿著圖示）→ 逐時 → 空品 → 紫外線／風／日出日落／舒適度 |
| 不做 | 廣告、雷達付費區、旅遊推薦、滑動切換小工具（做不到，見 AGENTS.md） |

## 3. 字

- 中文：Noto Sans TC（系統內建的思源黑體即可，不另外打包）。
- 數字：Outfit（打包 Light 200、Regular 400 兩種；tabular 等寬數字）。
- 字級（sp）：現在溫度 84／Light、明天大卡溫度 40／Light、卡片標題 13.5／Medium、內文 14、次要 12～12.5、7 日 12。
- 小工具（sp）：A 版溫度 40、4 天 12；C 版溫度 27、標題 11.5；最小不低於 11。

## 4. 間距與形狀

- 畫面左右 14dp；卡片間距 12dp；卡片內距 14dp；卡片圓角 20dp；小卡（2 欄）圓角 20dp、間距 10dp。
- chip：圓角全圓、上下 5 左右 11dp、1dp 框線。
- 小工具：C 版面板圓角 24dp；內部兩塊圓角 17dp；切換鈕 26×64dp、圓角 13dp，選中的圓點拉長成 6×16dp。

## 5. 元件規則

- **天氣圖示**：手繪向量（太陽、多雲時晴、雲、雨、月亮；之後補雷雨、霧），對應氣象署 WeatherCode，對照表放 `domain/WeatherIcon.kt`。
- **穿著圖示**：短袖、薄外套、外套、雨傘、口罩、防曬，和播報句同一套規則產生（F06）。
- **颱風卡**：只在有颱風時出現，橘紅漸層＋外框；兩格「家／學校」影響等級用 `danger`／`warn`／`ok` 上色。
- **空品卡**：AQI ≥101 時外框改 `warn`。
- **小工具警示**：4×1 沒空間放整行，颱風或空品橘色以上時在地點旁加小標籤（颱風優先）。
- **4×1 版面 A 的底**：設計稿是全透明加文字陰影；Glance 不能加文字陰影，所以改成很淡的半透明深色底（`bg_scrim`，hsl(230 30% 8%) α .28），淺色桌布才看得清楚。
- **資料過舊**：超過 3 小時沒更新，小工具右上角顯示「N 點更新」的灰字；APP 頂端顯示提示列。

| 位置 | 動作 |

| A 版 4 天區 | 開 APP 並捲到 7 日預報 |

## 7. 設定頁

由上而下分組，每個設定都有「測試」按鈕（倬的 UX 預設）：

1. **地點**：家、學校（縣市＋鄉鎮選單，或「用目前位置」）；目前定位權限狀態。
2. **資料來源**：氣象署授權碼、環境部金鑰（遮罩顯示、測試按鈕呼叫一次 API 顯示結果與錯誤）；環境部金鑰到期日提醒。
3. **提醒**：颱風突發通知（F18）、早上降雨提醒（F19，時間可調）、空品警戒通知。
4. **小工具**：更新頻率（30／60 分鐘）、預設版面（A／C）。
5. **上班日**：辦公日曆版本與「立即檢查更新」；手動標記某天上班／放假。
6. **備份**：分享備份、存到檔案、從檔案匯入（合併／取代）、復原到匯入前。
7. **Agent API 測試台**：選動作、填參數、執行，看 summary 與 data。

## 8. 健康檢查頁

清單式，每列：狀態圓點（`ok`／`warn`／`danger`）＋說明＋「前往設定」或「立即測試」按鈕。

- 定位權限（一律允許）、通知權限
- 電池最佳化豁免、ColorOS 自啟動、關聯啟動（語音總控要呼叫本 APP）
- 氣象署授權碼、環境部金鑰（含到期日）
- 最近一次更新時間與錯誤
- 小工具是否已放到桌面
- Agent API 狀態（describe 測試）
